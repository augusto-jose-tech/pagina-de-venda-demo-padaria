# 🍞 Página de Vendas DEMO — Padaria com Chatbot Embutido

Uma landing page moderna, elegante e totalmente responsiva desenvolvida para simular a experiência de um cardápio digital de padaria gourmet integrado a um assistente virtual (chatbot) automatizado.

---

## 🎯 Objetivo do Projeto
Este repositório foi construído exclusivamente como um ambiente de demonstração técnica para portfólio. O objetivo principal é apresentar a união de um design visual sofisticado orientado à experiência do usuário (UI/UX) com uma lógica funcional de atendimento automatizado via chat (sem conversões reais ou integrações pesadas de banco de dados).

---

## 🚀 Tecnologias Utilizadas

A arquitetura do projeto foi desenvolvida utilizando ferramentas nativas para garantir máxima performance:

* **HTML5** — Estruturação semântica avançada e foco em acessibilidade.
* **CSS3** — Design moderno utilizando variáveis nativas, Flexbox/Grid para responsividade absoluta e animações fluidas de digitação.
* **JavaScript (Vanilla)** — Lógica imperativa para controle dos estados do chatbot, simulação de respostas temporizadas e manipulação dinâmica do DOM.

---

## 📋 Funcionalidades em Destaque

* 🤖 **Chatbot Interativo (Fluxo Avançado):** Simulação em tempo real de atendimento ao cliente com opções clicáveis e tomada de decisões.
* 📱 **Design Mobile-First:** Interface limpa e minimalista perfeitamente otimizada para smartphones, tablets e computadores.
* 💬 **Indicador de Digitação Dinâmico:** Animações sutis que simulam a interação humana do atendente virtual.
* 🧾 **Extrato Automatizado:** Geração de um resumo descritivo ao final da simulação do pedido de forma totalmente visual.

## 🔧 Como Executar o Projeto Localmente

Se você deseja visualizar o projeto na sua máquina local, siga os passos abaixo:

1. **Clone este repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Navegue até o diretório do projeto:**
   ```bash
   cd pagina-de-venda-padaria
   ```

3. **Inicie a aplicação:**
   * Abra o arquivo `index.html` diretamente em qualquer navegador ou utilize o *Live Server* no VS Code.
